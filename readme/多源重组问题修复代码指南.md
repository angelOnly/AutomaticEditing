# AutomaticEditing 代码修改指南（Codex 直接执行版）

仓库：`angelOnly/AutomaticEditing`  
分支：`clean-highlight-reassembly`  
入口：`python run_web.py`

本文目标：把《凤凰新闻视频智能拆条系统_多源重组与Web问题修复方案.md》中偏文字描述的修复方案，整理成 Codex 可以直接执行的代码修改清单。请按本文顺序修改，不要跳步。

---

## 0. 总体执行原则

1. 先修复必现问题：高光重组 LLM 输入超长、原片预览黑屏、终止任务、任务名错误、字幕过大。
2. 再修复 AI 配音多视频强拆问题：`max_output_videos` 必须是上限，不是目标数量。
3. 最后做公共产物复用第一阶段：先用 `common_task + seed` 的折中方案，不一次性重构 `PipelineRunner` 的目录模型。
4. 所有新增函数都要尽量兼容旧任务目录。
5. 所有 Web API 返回字段都要兼容旧前端，避免页面直接崩。

### 1.3 新增 `_load_llm_timeline_digest()`

在 `step_content_analysis()` 前面插入：

```python
def _load_llm_timeline_digest(self) -> dict[str, Any]:
    """
    文本 Agent 专用压缩时间轴。
    优先读取 timeline_digest；兼容老任务：没有该步骤时，临时从 timeline 构造轻量 digest。
    """
    try:
        return self._load_step_json("timeline_digest")
    except Exception:
        timeline_data = self._load_step_json("timeline")
        timeline = timeline_data.get("timeline", [])
        llm_input_cfg = self.config.raw.get("llm_input", {})

        chunks: list[dict[str, Any]] = []
        for item in timeline:
            if not isinstance(item, dict):
                continue
            chunks.append({
                "chunk_id": item.get("chunk_id", ""),
                "time": f"{item.get('start', '')}-{item.get('end', '')}",
                "start_seconds": item.get("start_seconds", 0),
                "end_seconds": item.get("end_seconds", 0),
                "speech": compact_asr_for_llm(
                    item.get("asr_text", ""),
                    max_chars=int(llm_input_cfg.get("max_asr_chars_per_chunk", 240)),
                ),
                "visual": compact_text(
                    item.get("visual_summary", ""),
                    max_chars=int(llm_input_cfg.get("max_visual_chars_per_chunk", 120)),
                ),
                "screen_text": compact_list(
                    item.get("screen_text", []),
                    max_items=int(llm_input_cfg.get("max_screen_text_items", 3)),
                ),
                "people": compact_list(
                    item.get("visible_people", []),
                    max_items=int(llm_input_cfg.get("max_people_items", 3)),
                ),
                "scene": item.get("scene_type", ""),
                "visual_score": item.get("visual_value_score", 0),
                "hook_score": item.get("hook_score", 0),
                "flags": build_chunk_flags(item),
            })

        max_chunks = int(llm_input_cfg.get("max_digest_chunks_for_text_agent", 120))
        if max_chunks > 0 and len(chunks) > max_chunks:
            chunks = chunks[:max_chunks]

        return {
            "version": "inline_llm_timeline_digest_v1",
            "source_versions": {"timeline": self._step_version("timeline")},
            "video_duration_seconds": max(
                (float(x.get("end_seconds") or 0) for x in chunks),
                default=0.0,
            ),
            "chunks": chunks,
        }
```

## 2. 修复 Prompt，让高光重组明确读取 `timeline_digest`

文件：`newsclip_agent/prompts.py`

### 2.1 在 `VIDEO_UNDERSTANDING_PROMPT` 末尾追加

```text

【输入兼容规则】
1. 输入优先提供 timeline_digest，而不是完整 merged_timeline。
2. timeline_digest.chunks 是压缩时间轴，每个 chunk 包含：chunk_id、time、start_seconds、end_seconds、speech、visual、screen_text、people、scene、visual_score、hook_score、flags。
3. 你必须基于这些字段完成新闻主题、事实结构、关键人物、关键画面、风险和高光方向判断。
4. 不要要求完整 ASR 原文；speech 字段就是压缩后的语音内容。
5. 输出 JSON 结构保持原有要求不变。
```

### 2.2 在 `HIGHLIGHT_DETECTION_PROMPT` 末尾追加

```text

【timeline_digest 识别规则】
1. 优先读取 timeline_digest.chunks 进行高光识别。
2. speech 是该 chunk 的压缩语音摘要，visual 是画面摘要。
3. 候选片段的 start/end 必须基于 chunk 的 start_seconds/end_seconds 或相邻 chunk 合并推断。
4. 不允许返回不存在于 timeline_digest.chunks 时间范围外的片段。
5. 如果单个 chunk 不够完整，可以合并相邻 chunk，但必须保证新闻逻辑连续。
```

### 2.3 在 `HIGHLIGHT_REASSEMBLY_PROMPT` 末尾追加

```text

【重组输入规则】
1. 输入使用 timeline_digest 作为时间轴，不提供完整 merged_timeline。
2. selected_clips 的时间边界必须落在 timeline_digest.chunks 的 start_seconds/end_seconds 范围内。
3. 如果需要合并相邻 chunk，优先合并新闻逻辑连续、speech/visual 连续的 chunk。
4. 不得为了凑满 max_output_videos 强拆同一新闻链条。
5. output_mode=multiple 时，max_output_videos 是上限，不是必须输出数量。
```

### 3.1 修改 `web_app.py`：新增 source_request 预览兜底

在 `_resolve_task_source()` 后面插入：

```python
def _source_request_preview_items(task_dir: Path, task_id: str) -> list[dict[str, Any]]:
    request = read_json(task_dir / "input" / "source_request.json", {})
    items = request.get("source_items") or []
    previews: list[dict[str, Any]] = []

    for index, item in enumerate(items, start=1):
        if not isinstance(item, dict):
            continue

        source_type = str(item.get("source_type") or item.get("type") or "local")
        if source_type in {"local", "video"}:
            path_value = item.get("path") or item.get("input_video")
            if not path_value:
                continue
            try:
                path = _resolve_input_video(str(path_value))
                previews.append({
                    "label": item.get("display_name") or path.name,
                    "file": relpath(path, ROOT),
                    "url": f"/api/videos/preview?path={relpath(path, ROOT)}",
                    "source_index": index,
                })
            except Exception:
                continue
            continue

        if source_type in {"remote", "remote_ucms"}:
            remote = item.get("remote_video") or item
            if not isinstance(remote, dict):
                continue
            url = remote.get("preview_url") or remote.get("media_low_url") or remote.get("media_high_url") or ""
            if not url:
                continue
            previews.append({
                "label": item.get("display_name") or remote.get("display_name") or remote.get("name") or f"远程素材 {index}",
                "file": remote.get("name") or remote.get("remote_id") or remote.get("id") or "",
                "url": url,
                "source_index": index,
            })

    return previews
```

```python
def _terminate_process_tree(pid: int) -> None:
    if pid <= 0:
        return
    if os.name == "nt":
        subprocess.run(
            ["taskkill", "/PID", str(pid), "/T", "/F"],
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL,
            check=False,
        )
        return

    try:
        os.killpg(pid, signal.SIGTERM)
    except Exception:
        try:
            os.kill(pid, signal.SIGTERM)
        except ProcessLookupError:
            pass
```

### 4.4 新增取消接口

放在 `get_job_log()` 后面：

```python
@app.delete("/api/jobs/{job_id}")
def cancel_job(job_id: str) -> dict[str, Any]:
    if job_id not in JOBS:
        raise HTTPException(404, "job not found")

    with JOB_LOCK:
        job = JOBS[job_id]
        status = job.get("status")

        if status == "pending":
            try:
                PENDING_JOB_IDS.remove(job_id)
            except ValueError:
                pass
            job["status"] = "cancelled"
            job["returncode"] = -9
            job["finished_at"] = datetime.now().isoformat(timespec="seconds")
            job["user_message"] = "任务已取消。"
            _persist_job(job)
            _schedule_jobs()
            return _public_job(job)

        if status != "running":
            return _public_job(job)

        pid = int(job.get("pid") or 0)
        _terminate_process_tree(pid)

        process = job.get("process")
        if process:
            try:
                process.wait(timeout=3)
            except Exception:
                pass

        log_file = job.get("log_file")
        if log_file:
            try:
                log_file.write("\n=== job cancelled by user ===\n")
                log_file.flush()
                log_file.close()
            except Exception:
                pass

        job["status"] = "cancelled"
        job["returncode"] = -9
        job["finished_at"] = datetime.now().isoformat(timespec="seconds")
        job["user_message"] = "任务已手动终止。"
        _persist_job(job)
        _schedule_jobs()
        return _public_job(job)
```

def _merge_short_video_plan_items(self, videos: list[dict[str, Any]], max_count: int = 2) -> list[dict[str, Any]]:
    valid = [v for v in videos if isinstance(v, dict)]
    if len(valid) <= max_count:
        return valid

    groups: list[list[dict[str, Any]]] = [[] for _ in range(max_count)]
    for idx, item in enumerate(valid):
        groups[idx % max_count].append(item)

    merged_items: list[dict[str, Any]] = []
    for group_idx, group in enumerate(groups, start=1):
        if not group:

        first = group[0]
        source_clip_ids: list[str] = []
        must_keep_fact_points: list[str] = []
        optional_fact_points: list[str] = []

                if isinstance(shot, dict):
                    editing_structure.append(dict(shot))

            max(
                sum(float(x.get("target_duration_seconds") or 30) for x in group),
                float(self.options.min_output_video_seconds),
            ),
            float(self.options.max_output_video_seconds),

            "merged_from_short_video_ids": [str(x.get("short_video_id") or "") for x in group],
        })

voice_by_id = {x.get("short_video_id"): x for x in voiceover.get("scripts", []) if isinstance(x, dict)}

```python
def _source_workspace_hash(req: RunRequest, items: list[dict[str, Any]]) -> str:
    payload_items: list[dict[str, Any]] = []
    for index, item in enumerate(items, start=1):
        source_type = str(item.get("source_type") or item.get("type") or "local")
        if source_type in {"local", "video"}:
            path = _resolve_input_video(str(item.get("path") or item.get("input_video")))
            payload_items.append({"order": index, "source_type": "local", **_video_fingerprint(path)})
        else:
            remote_video = item.get("remote_video") or item
            payload_items.append({"order": index, "source_type": "remote_ucms", "remote": _remote_video_fingerprint(remote_video)})

    payload = {
        "sources": payload_items,
        "aspect_ratio": req.aspect_ratio,
        "chunk_seconds": req.chunk_seconds,
        "frame_interval": req.frame_interval,
        "vision_max_frames_per_chunk": WORKFLOW_DEFAULTS.get("vision_max_frames_per_chunk", 6),
    }
    raw = json.dumps(payload, ensure_ascii=False, sort_keys=True)
    return hashlib.sha256(raw.encode("utf-8")).hexdigest()[:16]


def _source_workspace_id(req: RunRequest, items: list[dict[str, Any]]) -> str:

    if _common_task_completed(common_task_id):
        return None

    active = _find_active_job_by_task_id(common_task_id)
    if active:
        return active

    source_request_path = common_task_dir / "input" / "source_request.json"

        "task_id": common_task_id,

        "source_workspace_id": source_workspace_id,

        "force_remote_download": req.force_remote_download,
        "output_mode": "single",
        "max_output_videos": 1,
        "min_output_video_seconds": req.min_output_video_seconds,
        "max_output_video_seconds": req.max_output_video_seconds,
        "aspect_ratio": req.aspect_ratio,
        "created_at": datetime.now().isoformat(timespec="seconds"),
    })

    common_req = req.model_copy(deep=True)
    common_req.task_id = common_task_id
    common_req.production_mode = "ai_voiceover"
    common_req.output_mode = "single"
    common_req.max_output_videos = 1
    common_req.only_analysis = True
    common_req.skip_tts = True
    common_req.skip_render = True
    common_req.require_tts = False
    common_req.rerun_from = None
    common_req.rerun = None

    cmd = _build_run_command(common_req, common_task_id, None, None, source_request_path)
    cmd.extend(["--rerun-from", "metadata"])

    job_id = f"job_{datetime.now().strftime('%Y%m%d_%H%M%S')}_{uuid.uuid4().hex[:6]}"
    log_dir = ensure_dir(common_task_dir / "web_jobs")
    log_path = log_dir / f"{job_id}.log"

    job = {
        "job_id": job_id,
        "job_type": "common",
        "task_id": common_task_id,
        "source_workspace_id": source_workspace_id,
        "pid": None,
        "cmd": cmd,

        "log_path": str(log_path),
        "created_at": datetime.now().isoformat(timespec="seconds"),
        "started_at": "",
        "status": "pending",
        "returncode": None,
        "submitted_by": req.client_id or "anonymous",
        "task_fingerprint": source_workspace_id,
    }

def _release_waiting_common_jobs(source_workspace_id: str) -> None:
    common_task_id = _common_task_id(source_workspace_id)
    if not _common_task_completed(common_task_id):
        return

    common_task_dir = OUTPUTS_DIR / common_task_id
    for job in JOBS.values():
        if job.get("status") != "waiting_common":
            continue
        if job.get("source_workspace_id") != source_workspace_id:
            continue

        task_id = job.get("task_id")
        if not task_id:
            continue
        task_dir = ensure_dir(OUTPUTS_DIR / task_id)
        _seed_common_outputs(common_task_dir, task_dir)
        job["status"] = "pending"
        job["user_message"] = "公共分析已完成，开始执行模式差异步骤。"
        PENDING_JOB_IDS.append(job["job_id"])
        _persist_job(job)
```

新增 seed 函数：

```python
def _seed_common_outputs(common_task_dir: Path, task_dir: Path) -> None:
    common_manifest = read_json(common_task_dir / "manifest.json", {})
    common_steps = common_manifest.get("steps", {})
    copied_steps: dict[str, Any] = {}
    copied_versions: dict[str, str] = {}

    for step in COMMON_REUSABLE_STEPS:
        step_info = common_steps.get(step) or {}
        if step_info.get("status") not in {"success", "partial_success"}:
            continue
        output = step_info.get("output")
        if not output:
            continue
        source_output = common_task_dir / output
        if not source_output.exists():
            continue
        source_copy_root = source_output.parent
        target_copy_root = task_dir / relpath(source_copy_root, common_task_dir)
        _copy_reusable_path(source_copy_root, target_copy_root)
        copied_steps[step] = step_info
        if step_info.get("version"):
            copied_versions[step] = step_info["version"]
        print(f"复用公共步骤: {step}")

    if not copied_steps:
        return

    manifest = read_json(task_dir / "manifest.json", {})
    manifest.setdefault("steps", {}).update(copied_steps)
    manifest.setdefault("current_versions", {}).update(copied_versions)
    manifest["reused_common_task_id"] = common_task_dir.name
    manifest["reused_common_steps"] = list(copied_steps)
    manifest["updated_at"] = datetime.now().isoformat(timespec="seconds")
    write_json(task_dir / "manifest.json", manifest)
```
