# 高光片段重组模式：技术实现文档 v1

## 1. 开发目标

在现有 Phoenix Newsclip Agent 中新增一条“高光片段原声重组”流水线。

该流水线复用现有代码中的视频预处理、ASR、抽帧、多模态理解、时间轴融合、新闻理解、高光识别、manifest 缓存、版本目录、Web 任务运行、文件预览和视频预览能力，只新增必要的重组规划、cut_plan 构建、渲染策略和 Web 交互。

目标不是重写一个新系统，而是在现有 pipeline 里增加一个新的 production mode：

```text
mode = ai_voiceover       # 现有：AI 配音解说视频
mode = highlight_reassembly  # 新增：高光片段原声重组
```

### 5.4 Prompt 要点

新增 `prompts.HIGHLIGHT_REASSEMBLY_PROMPT`：

```text
你是凤凰卫视新闻短视频编辑。当前任务不是生成 AI 解说，不要改写新闻文案，也不要规划 TTS。你的任务是从候选高光中选择可直接使用原声的片段，按新闻逻辑重组成一条或多条短视频。

你必须遵守：
1. 不为了分数高就机械拼接片段。
2. 每个片段必须语义完整，不从半句话开始或结束。
3. 重组顺序不能改变原视频表达的因果、立场和语义。
4. 如果重排有误导风险，应保持原始时间顺序。
5. 原声不清楚、上下文缺失、风险过高的片段不得自动进入成片。
6. 输出 adjusted_start / adjusted_end，必要时扩展到完整句边界。
7. 输出 selected_clips、excluded_clips 和风险说明。
```

## 6. step_highlight_reassembly_plan 实现

新增方法：

```python
def step_highlight_reassembly_plan(self) -> None:
    timeline = self._load_step_json("timeline")
    video_analysis = self._load_step_json("video_understanding")
    candidate_clips = self._load_step_json("highlight_detection")

    input_data = {
        "run_options": {
            "production_mode": self.options.production_mode,
            "reassembly_output_mode": self.options.reassembly_output_mode,
            "reassembly_sort_mode": self.options.reassembly_sort_mode,
            "reassembly_target_seconds": self.options.reassembly_target_seconds,
            "reassembly_max_clip_count": self.options.reassembly_max_clip_count,
            "min_clip_seconds": self.options.reassembly_min_clip_seconds,
            "max_clip_seconds": self.options.reassembly_max_clip_seconds,
        },
        "timeline": timeline,
        "video_analysis": video_analysis,
        "candidate_clips": candidate_clips,
    }

    input_hash = stable_hash({
        "input": input_data,
        "prompt_version": self.options.prompt_version or "highlight_reassembly_v1",
    })

    if self._can_reuse("highlight_reassembly_plan", input_hash):
        print("复用缓存: highlight_reassembly_plan")
        return

    version, vdir = self._version_dir("highlight_reassembly_plan", "agents/highlight_reassembly")
    ensure_dir(vdir)
    write_json(vdir / "input.json", input_data)
    write_text(vdir / "prompt.txt", prompts.HIGHLIGHT_REASSEMBLY_PROMPT)

    result = self._call_llm_json(
        client=self.llm_text,
        prompt=prompts.HIGHLIGHT_REASSEMBLY_PROMPT,
        input_data=input_data,
        step="highlight_reassembly_plan",
    )

    out = write_json(vdir / "highlight_reassembly_plan.json", result)
    self._write_status(vdir, self._base_status("highlight_reassembly_plan", version, input_hash, [out]))
    self._record_step(
        step="highlight_reassembly_plan",
        version=version,
        status="success",
        output=relpath(out, self.task_dir),
        input_hash=input_hash,
        output_files=[out],
    )
```

如果当前没有 `_call_llm_json()` 这样的统一函数，就参考现有 `step_video_understanding()` / `_run_agent_step()` 的调用方式实现。

### 7.3 构建规则

`step_reassembly_cut_plan()` 应执行：

```text
1. 读取 highlight_reassembly_plan。
2. 遍历 output_videos。
3. 校验每个 selected_clip 的时间码。
4. 将 adjusted_start/adjusted_end 转为 source_start/source_end。
5. 过滤低于 min_clip_seconds 的片段，除非 allow_short_clip=true。
6. 限制单段 max_clip_seconds。
7. 累加 target_start。
8. 生成 output_file。
9. 标记 duration_status。
10. 如果没有可用片段，block。
```

### 7.4 伪代码

```python
def step_reassembly_cut_plan(self) -> None:
    plan = self._load_step_json("highlight_reassembly_plan")
    input_hash = stable_hash({
        "highlight_reassembly_plan": self._step_version("highlight_reassembly_plan"),
        "aspect": self.options.aspect_ratio,
        "production_mode": self.options.production_mode,
    })
    if self._can_reuse("reassembly_cut_plan", input_hash):
        print("复用缓存: reassembly_cut_plan")
        return

    version, vdir = self._version_dir("reassembly_cut_plan", "edit/reassembly_cut_plan")
    ensure_dir(vdir)

    output_videos = []
    for item in plan.get("output_videos", []):
        rid = item.get("reassembly_id") or f"hr_{len(output_videos)+1:03d}"
        clips = []
        target = 0.0
        blocked_reasons = []
        warnings = []

        for idx, clip in enumerate(item.get("selected_clips", []), start=1):
            start = timecode_to_seconds(clip.get("adjusted_start") or clip.get("source_start"))
            end = timecode_to_seconds(clip.get("adjusted_end") or clip.get("source_end"))
            if end <= start:
                warnings.append(f"{clip.get('source_clip_id')} invalid time range")
                continue
            duration = end - start
            if duration < self.options.reassembly_min_clip_seconds:
                warnings.append(f"{clip.get('source_clip_id')} shorter than min clip seconds")
                continue
            if duration > self.options.reassembly_max_clip_seconds:
                end = start + self.options.reassembly_max_clip_seconds
                duration = self.options.reassembly_max_clip_seconds
                warnings.append(f"{clip.get('source_clip_id')} truncated to max clip seconds")

            clips.append({
                "clip_id": f"{rid}_{idx:03d}",
                "source_clip_id": clip.get("source_clip_id", ""),
                "source_start": seconds_to_timecode(start, ms=True),
                "source_end": seconds_to_timecode(end, ms=True),
                "target_start": seconds_to_timecode(target, ms=True),
                "duration_seconds": round(duration, 3),
                "original_audio_volume": 1.0,
                "keep_original_audio": True,
                "role": clip.get("role", ""),
                "transition_after": clip.get("transition_after", "hard_cut"),
                "crop_mode": "fit_blur" if self.options.aspect_ratio == "9:16" else "original",
            })
            target += duration

        if not clips:
            blocked_reasons.append("no valid clips for reassembly")

        output_videos.append({
            "reassembly_id": rid,
            "output_file": f"highlight_reassembly_{rid}_draft.mp4",
            "title": item.get("title", ""),
            "aspect_ratio": self.options.aspect_ratio,
            "target_resolution": "1080x1920" if self.options.aspect_ratio == "9:16" else "1920x1080",
            "audio_policy": "original_audio",
            "video_duration_seconds": round(target, 3),
            "duration_status": "blocked" if blocked_reasons else "ok",
            "risk_review_required": item.get("risk_review_required", False),
            "clips": clips,
            "warnings": warnings,
            "blocked_reasons": blocked_reasons,
        })

    out = write_json(vdir / "reassembly_cut_plan.json", {
        "project_id": self.task_id,
        "production_mode": "highlight_reassembly",
        "source_video": self.manifest["source_video"],
        "output_videos": output_videos,
    })

    status = "success" if any(v["duration_status"] != "blocked" for v in output_videos) else "failed"
    self._write_status(vdir, self._base_status("reassembly_cut_plan", version, input_hash, [out]))
    self._record_step(
        step="reassembly_cut_plan",
        version=version,
        status=status,
        output=relpath(out, self.task_dir),
        input_hash=input_hash,
        output_files=[out],
    )
```

## 8. 新增 reassembly_render

### 8.1 不要复用 AI 配音混音逻辑

现有 `_render_one()` 是为 AI 配音/混合原声设计的，会处理：

```text
voiceover_enabled
evidence_audio_windows
AI voiceover volume
原声压低/静音
amix 混音
字幕烧录
```

高光重组模式不应走这些逻辑。应新增 `_render_reassembly_one()`，保持原视频原声。

### 8.2 渲染策略

第一版建议：

```text
1. 每个 clip 用 ffmpeg 精准裁切。
2. 保留原声。
3. 按目标比例 scale/pad。
4. concat 拼接。
5. 不混入 TTS。
6. 可选转场，但第一版先硬切。
```

### 8.3 伪代码

```python
def step_reassembly_render(self) -> None:
    plan = self._load_step_json("reassembly_cut_plan")
    input_hash = stable_hash({"reassembly_cut_plan": self._step_version("reassembly_cut_plan")})
    if self._can_reuse("reassembly_render", input_hash):
        print("复用缓存: reassembly_render")
        return

    version, base_dir = self._version_dir("reassembly_render", "edit/reassembly_drafts")
    outputs = []
    skipped_outputs = []

    for video in plan.get("output_videos", []):
        rid = video["reassembly_id"]
        if video.get("duration_status") == "blocked":
            skipped_outputs.append({
                "reassembly_id": rid,
                "status": "skipped",
                "reason": "reassembly_cut_plan_blocked",
                "blocked_reasons": video.get("blocked_reasons", []),
            })
            continue
        vdir = ensure_dir(base_dir / rid)
        out = vdir / video["output_file"]
        self._render_reassembly_one(video, out)
        outputs.append({"reassembly_id": rid, "file": relpath(out, self.task_dir)})

    out_index = write_json(base_dir / "reassembly_render_outputs.json", {
        "version": version,
        "outputs": outputs,
        "skipped_outputs": skipped_outputs,
    })

    status = "success" if outputs else "failed"
    self._record_step(
        step="reassembly_render",
        version=version,
        status=status,
        output=relpath(out_index, self.task_dir),
        input_hash=input_hash,
        output_files=[out_index],
    )
```

### 8.4 `_render_reassembly_one()`

```python
def _render_reassembly_one(self, video: dict[str, Any], output_path: Path) -> None:
    source = self._source_video()
    temp_dir = ensure_dir(output_path.parent / "_clips")
    clip_files = []

    for idx, clip in enumerate(video.get("clips", []), start=1):
        clip_file = temp_dir / f"{video['reassembly_id']}_{idx:03d}.mp4"
        vf = self._video_filter(video)
        run_cmd([
            "ffmpeg", "-y", "-hide_banner", "-loglevel", "error",
            "-ss", clip["source_start"],
            "-to", clip["source_end"],
            "-i", str(source),
            "-vf", vf,
            "-c:v", "libx264",
            "-preset", "veryfast",
            "-c:a", "aac",
            "-ar", "48000",
            "-af", "volume=1.0",
            str(clip_file),
        ])
        clip_files.append(clip_file)

    if not clip_files:
        raise RuntimeError(f"{video['reassembly_id']} 没有可渲染片段")

    concat_file = temp_dir / f"{video['reassembly_id']}_concat.txt"
    write_text(concat_file, "".join(f"file '{str(p).replace(chr(92), '/')}'\n" for p in clip_files))

    run_cmd([
        "ffmpeg", "-y", "-hide_banner", "-loglevel", "error",
        "-f", "concat", "-safe", "0", "-i", str(concat_file),
        "-c", "copy",
        str(output_path),
    ])
```

如果 concat copy 因编码参数不一致失败，可改成重新编码拼接：

```bash
ffmpeg -f concat -safe 0 -i concat.txt -c:v libx264 -c:a aac output.mp4
```

## 18. 关键注意事项

### 18.1 不要让高光重组模式走现有 AI 配音 cut_plan

现有 `step_cut_plan()` 和 `_render_one()` 已经深度绑定：

```text
voiceover_script
tts_outputs
voiceover_duration_seconds
evidence_audio_windows
amix 混音
AI 配音与原声冲突检查
```

高光重组模式如果强行复用，很容易出现：

```text
因为没有 TTS 被 block
因为 voiceover_duration=0 导致质量检查异常
因为 suppress_unplanned_original_audio 把原声压掉
因为 evidence_windows 逻辑误判
```

所以应复用底层工具函数和渲染片段逻辑，但不要复用 AI 配音 cut_plan 语义。

### 18.2 不要跳过高光识别

高光重组仍应复用：

```text
metadata
audio_extract
frame_extract
chunk_build
asr
vision
timeline
video_understanding
highlight_detection
```

只是不走：

```text
short_video_planning
editing_script
voiceover_script
tts
subtitles
cut_plan
render
```

而是改走：

```text
highlight_reassembly_plan
reassembly_cut_plan
reassembly_render
```

### 18.3 重组模式的主要质量标准不是 TTS 对齐，而是上下文完整

AI 配音模式关注：

```text
TTS 是否成功
配音和画面是否对齐
配音覆盖比例
字幕是否跟随 TTS
```

高光重组模式关注：

```text
片段是否完整
原声是否清楚
重排是否误导
片段衔接是否自然
总时长是否合理
```

因此质量检查必须换一套标准。
