# 凤凰新闻视频智能拆条系统：远程视频源接入开发技术方案

> 仓库：`angelOnly/AutomaticEditing`  
> 分支：`clean-highlight-reassembly`  
> 启动方式保持不变：`python run_web.py`  
> 目标：在原有“读取项目本地 `videos` 目录”的基础上，新增公司内网 UCMS 远程视频源入口，用户可在 Web 工作台选择远程素材，系统自动下载/缓存到本地后复用现有 pipeline。

---

## 1. 当前代码现状

### 1.1 总体流程

项目 README 已明确该系统是“凤凰新闻视频智能拆条系统”，包含视频预处理、FunASR 转写、视觉 chunk 分析、ASR + 画面理解融合、高光识别、AI 解说、OmniVoice 配音、字幕和 FFmpeg 粗剪等流程。Web 启动方式是：

```powershell
python run_web.py
```

`run_web.py` 只负责找可用端口并启动 `web_app:app`：

```python
host = "127.0.0.1"
port = find_free_port(host=host, start=7860)
uvicorn.run("web_app:app", host=host, port=port, reload=False)
```

因此本次改造不要改启动方式，新增逻辑应放在 `web_app.py`、新增业务模块、`web_static` 前端文件和 `config.toml` 中。

### 1.2 Web 端现在只支持本地 videos 目录

`web_app.py` 顶部固定了几个目录：

```python
ROOT = Path(__file__).resolve().parent
OUTPUTS_DIR = ROOT / "outputs"
VIDEOS_DIR = ROOT / "videos"
STATIC_DIR = ROOT / "web_static"
RUNNER = ROOT / "run_pipeline.py"
```

当前 `/api/videos` 实现只扫描 `VIDEOS_DIR`：

```python
@app.get("/api/videos")
def list_videos() -> list[dict[str, Any]]:
    if not VIDEOS_DIR.exists():
        return []
    videos = []
    for path in sorted(VIDEOS_DIR.glob("*")):
        if path.suffix.lower() not in {".mp4", ".mov", ".mkv", ".m4v", ".avi"}:
            continue
        videos.append({
            "name": path.name,
            "path": relpath(path, ROOT),
            "size_mb": round(path.stat().st_size / 1024 / 1024, 2),
            "updated_at": datetime.fromtimestamp(path.stat().st_mtime).isoformat(timespec="seconds"),
        })
    return videos
```

当前视频预览也只能走本地文件：

```python
@app.get("/api/videos/preview")
def preview_video(path: str):
    file_path = _resolve_input_video(path)
    return FileResponse(str(file_path))
```

上传视频保存到 `videos` 目录，删除视频也只删除本地文件。

### 1.3 任务启动前强制 input_video 是项目目录内文件

`/api/run` 里会先调用 `_resolve_input_video(req.input_video)`：

```python
input_path = _resolve_input_video(req.input_video) if req.input_video else None
```

而 `_resolve_input_video` 明确要求路径存在，并且必须在项目目录内：

```python
def _resolve_input_video(input_video: str) -> Path:
    raw = Path(input_video)
    if raw.is_absolute():
        path = raw.resolve()
    else:
        path = (ROOT / raw).resolve()
    if not path.exists() or not path.is_file():
        raise HTTPException(404, "input video not found")
    if ROOT != path and ROOT not in path.parents:
        raise HTTPException(400, "input must be inside project directory")
    return path
```

所以远程接口返回的 URL 不能直接传给 pipeline。必须先下载到项目目录内某个缓存目录或 `videos` 目录，再把本地路径传给 `run_pipeline.py`。

### 1.4 pipeline 本身已经适合复用本地文件

`run_pipeline.py` 只是转发到 `newsclip_agent.pipeline.main()`：

```python
from newsclip_agent.pipeline import main

if __name__ == "__main__":
    raise SystemExit(main())
```

`PipelineRunner._init_task()` 在首次运行时会把 `--input` 对应本地文件复制到任务目录：

```python
source = Path(self.options.input).resolve()
input_dst = self.task_dir / "input" / ("source" + source.suffix.lower())
copy_or_link(source, input_dst)
```

后续 metadata、音频提取、抽帧、渲染都通过 `self._source_video()` 获取任务目录内的源视频。因此远程视频只要在提交任务前变成本地文件，后续流程无需大改。

### 1.5 前端目前只有“本地素材列表”

`web_static/index.html` 左侧只有“视频素材”区域，包含上传和刷新按钮，列表容器是 `videoList`。

`web_static/app.js` 的 `loadVideos()` 只请求 `/api/videos`，渲染本地素材；点击后把 `state.selectedVideo` 设为该本地视频，并通过 `/api/videos/preview?path=...` 预览。

`runSelected()` 里只有两种启动方式：

```javascript
} else if (state.selectedVideo) {
  req.input_video = state.selectedVideo.path;
  req.task_id = null;
} else if (state.selectedTask) {
  req.task_id = state.selectedTask;
} else {
  alert("请选择一个视频素材或已有任务。");
  return;
}
```

因此前端也需要新增远程素材列表、远程筛选参数、远程选择状态，以及启动时传递远程视频标识。

## 2. 需求理解与推荐方案

### 2.1 远程接口

公司内网接口：

```http
POST https://ucms.ifeng.com/api/ve/list
Content-Type: application/json

{
  "body": {
    "query": [
      {"key": "from", "type": "=", "value": "record"},
      {"key": "record_station", "type": "=", "value": "浦项高清卫星-凤凰咨询台"}
    ],
    "pagination": {
      "current": 1,
      "pageSize": 30
    }
  }
}
```

支持的 `record_station`：

```text
浦项专线-凤凰咨询台
浦项高清卫星-凤凰咨询台
资讯台高清卫星
资讯台高清
bak资讯台高清卫星
bak资讯台高清
浦项高清卫星-凤凰资讯台-Backup
```

返回数据中，`mediaHigh` / `mediaLow` / `previewImage` 是 JSON 字符串，不是对象，需要二次 `json.loads`。每条素材关键字段：

```json
{
  "id": 14373009,
  "guid": "2ad0c6ef-e0b8-4786-a5ed-9a334db94c17",
  "name": "20260529_000429",
  "duration": "300.0",
  "createTime": "2026-05-29 00:04:29",
  "recordStation": "浦项高清卫星-凤凰咨询台",
  "tvStation": "凤凰卫视资讯台",
  "mediaHigh": "{...\"url\":\"http://...init.mp4\"...}",
  "mediaLow": "{...\"url\":\"http://...init.mp4\"...}",
  "previewImage": "{...\"path\":\"http://...jpg,http://...jpg\"...}"
}
```

### 2.2 核心设计原则

不要让 pipeline 支持 URL。原因：

1. `ffprobe`、`ffmpeg` 虽可读部分 HTTP URL，但内网鉴权、断点、失败重试、缓存和任务复用都会变复杂。
2. 当前 pipeline 已经围绕本地文件做缓存、复制和 task manifest。
3. 远程 URL 可能包含中文路径，直接传 ffmpeg 更容易踩编码和转义问题。

推荐方案：

```text
Web 前端选择远程素材
        ↓
web_app.py /api/remote-videos 查询 UCMS 列表
        ↓
用户点击远程素材，先用 mediaLow 或 mediaHigh 预览
        ↓
用户点击开始分析
        ↓
web_app.py /api/run 发现 remote_video，下载到 data/remote_videos/<station>/<id>_<name>.mp4
        ↓
得到本地 path
        ↓
复用现有 _build_run_command(... --input 本地path ...)
        ↓
run_pipeline.py / PipelineRunner 不需要理解远程源
```

## 5. 新增 `newsclip_agent/remote_ucms.py`

新增模块职责：

1. 读取 UCMS 配置。
2. 查询远程视频列表。
3. 解析 `mediaHigh`、`mediaLow`、`previewImage` JSON 字符串。
4. 标准化返回给前端的字段。
5. 按远程视频 `id/guid/name/station` 生成稳定本地缓存路径。
6. 下载远程视频到本地，支持复用已下载文件。

### 5.1 可直接新增的代码

```python
# newsclip_agent/remote_ucms.py
from __future__ import annotations

import json
import re
import urllib.error
import urllib.request
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path
from typing import Any

from .config import ProjectConfig
from .utils import ensure_dir, relpath, write_json, read_json

VIDEO_SUFFIX = ".mp4"


@dataclass(frozen=True)
class RemoteVideoSourceConfig:
    enabled: bool
    api_url: str
    default_record_station: str
    default_page_size: int
    request_timeout_seconds: int
    connect_timeout_seconds: int
    cache_dir: Path
    prefer_quality: str
    record_stations: list[str]
    headers: dict[str, str]


def load_remote_ucms_config(project_config: ProjectConfig) -> RemoteVideoSourceConfig:
    raw = project_config.raw.get("remote_ucms", {})
    root = project_config.root_dir
    cache_dir = Path(str(raw.get("cache_dir", "data/remote_videos")))
    if not cache_dir.is_absolute():
        cache_dir = root / cache_dir
    return RemoteVideoSourceConfig(
        enabled=bool(raw.get("enabled", False)),
        api_url=str(raw.get("api_url", "https://ucms.ifeng.com/api/ve/list")),
        default_record_station=str(raw.get("default_record_station", "浦项高清卫星-凤凰咨询台")),
        default_page_size=int(raw.get("default_page_size", 30)),
        request_timeout_seconds=int(raw.get("request_timeout_seconds", 20)),
        connect_timeout_seconds=int(raw.get("connect_timeout_seconds", 5)),
        cache_dir=cache_dir,
        prefer_quality=str(raw.get("prefer_quality", "high")).lower(),
        record_stations=[str(x) for x in raw.get("record_stations", [])],
        headers={str(k): str(v) for k, v in raw.get("headers", {}).items()},
    )


def list_ucms_videos(
    cfg: RemoteVideoSourceConfig,
    *,
    record_station: str | None = None,
    current: int = 1,
    page_size: int | None = None,
) -> dict[str, Any]:
    if not cfg.enabled:
        return {"items": [], "pagination": {"current": current, "pageSize": page_size or cfg.default_page_size, "total": 0}}

    station = record_station or cfg.default_record_station
    size = int(page_size or cfg.default_page_size)
    payload = {
        "body": {
            "query": [
                {"key": "from", "type": "=", "value": "record"},
                {"key": "record_station", "type": "=", "value": station},
            ],
            "pagination": {"current": int(current), "pageSize": size},
        }
    }
    raw = _post_json(cfg.api_url, payload, headers=cfg.headers, timeout=cfg.request_timeout_seconds)
    if int(raw.get("code", -1)) != 0:
        raise RuntimeError(f"UCMS 接口返回失败: {raw.get('message') or raw}")

    data = raw.get("data") or {}
    items = [normalize_ucms_item(item, prefer_quality=cfg.prefer_quality) for item in data.get("list", [])]
    return {
        "items": items,
        "pagination": data.get("pagination", {"current": current, "pageSize": size, "total": len(items)}),
        "record_stations": cfg.record_stations,
        "default_record_station": cfg.default_record_station,
    }


def normalize_ucms_item(item: dict[str, Any], *, prefer_quality: str = "high") -> dict[str, Any]:
    media_high = _loads_json_field(item.get("mediaHigh"))
    media_low = _loads_json_field(item.get("mediaLow"))
    preview = _loads_json_field(item.get("previewImage"))
    high_url = str(media_high.get("url") or "")
    low_url = str(media_low.get("url") or "")
    selected_url = high_url if prefer_quality == "high" and high_url else low_url or high_url
    preview_paths = []
    if preview.get("path"):
        preview_paths = [x.strip() for x in str(preview.get("path")).split(",") if x.strip()]

    duration = _safe_float(item.get("duration"), 0.0)
    remote_id = str(item.get("id") or item.get("guid") or item.get("name") or "")
    name = str(item.get("name") or remote_id or "remote_video")
    station = str(item.get("recordStation") or item.get("record_station") or "")

    return {
        "source_type": "remote_ucms",
        "remote_id": remote_id,
        "id": item.get("id"),
        "guid": item.get("guid", ""),
        "name": name,
        "display_name": f"{name} · {station}" if station else name,
        "duration": duration,
        "duration_text": _format_duration(duration),
        "create_time": item.get("createTime", ""),
        "record_station": station,
        "tv_station": item.get("tvStation", ""),
        "mime_type": item.get("mimeType", ""),
        "aspect": item.get("aspect", ""),
        "media_high_url": high_url,
        "media_low_url": low_url,
        "download_url": selected_url,
        "preview_url": low_url or high_url,
        "preview_images": preview_paths,
        "raw": item,
    }


def download_ucms_video(
    cfg: RemoteVideoSourceConfig,
    remote_video: dict[str, Any],
    *,
    root_dir: Path,
    force: bool = False,
) -> dict[str, Any]:
    normalized = normalize_ucms_item(remote_video, prefer_quality=cfg.prefer_quality) if "download_url" not in remote_video else remote_video
    url = normalized.get("download_url") or normalized.get("media_high_url") or normalized.get("media_low_url")
    if not url:
        raise RuntimeError("远程视频没有可下载 URL")

    station = _safe_path_part(normalized.get("record_station") or "unknown_station")
    name = _safe_path_part(normalized.get("name") or "remote_video")
    rid = _safe_path_part(str(normalized.get("remote_id") or normalized.get("id") or normalized.get("guid") or "unknown"))
    target_dir = ensure_dir(cfg.cache_dir / station)
    target = target_dir / f"{rid}_{name}{VIDEO_SUFFIX}"
    meta_path = target.with_suffix(".json")

    if target.exists() and target.stat().st_size > 0 and not force:
        return {
            "downloaded": False,
            "path": relpath(target, root_dir),
            "absolute_path": str(target.resolve()),
            "size_mb": round(target.stat().st_size / 1024 / 1024, 2),
            "metadata": read_json(meta_path, {}),
        }

    tmp = target.with_suffix(".downloading")
    _download_file(url, tmp, headers=cfg.headers, timeout=cfg.request_timeout_seconds)
    tmp.replace(target)
    meta = {
        "source_type": "remote_ucms",
        "downloaded_at": datetime.now().isoformat(timespec="seconds"),
        "download_url": url,
        "remote_video": normalized,
        "local_path": relpath(target, root_dir),
    }
    write_json(meta_path, meta)
    return {
        "downloaded": True,
        "path": relpath(target, root_dir),
        "absolute_path": str(target.resolve()),
        "size_mb": round(target.stat().st_size / 1024 / 1024, 2),
        "metadata": meta,
    }


def _post_json(url: str, payload: dict[str, Any], *, headers: dict[str, str], timeout: int) -> dict[str, Any]:
    data = json.dumps(payload, ensure_ascii=False).encode("utf-8")
    req = urllib.request.Request(
        url,
        data=data,
        headers={"Content-Type": "application/json", **headers},
        method="POST",
    )
    try:
        with urllib.request.urlopen(req, timeout=timeout) as resp:
            charset = resp.headers.get_content_charset() or "utf-8"
            return json.loads(resp.read().decode(charset, errors="replace"))
    except urllib.error.URLError as exc:
        raise RuntimeError(f"请求 UCMS 失败: {exc}") from exc


def _download_file(url: str, target: Path, *, headers: dict[str, str], timeout: int) -> None:
    ensure_dir(target.parent)
    req = urllib.request.Request(url, headers=headers, method="GET")
    try:
        with urllib.request.urlopen(req, timeout=timeout) as resp, target.open("wb") as out:
            while True:
                chunk = resp.read(1024 * 1024)
                if not chunk:
                    break
                out.write(chunk)
    except Exception:
        if target.exists():
            target.unlink(missing_ok=True)
        raise


def _loads_json_field(value: Any) -> dict[str, Any]:
    if isinstance(value, dict):
        return value
    if not value:
        return {}
    try:
        parsed = json.loads(str(value))
        return parsed if isinstance(parsed, dict) else {}
    except Exception:
        return {}


def _safe_float(value: Any, default: float = 0.0) -> float:
    try:
        return float(value)
    except Exception:
        return default


def _format_duration(seconds: float) -> str:
    seconds = max(0, int(round(seconds)))
    return f"{seconds // 60:02d}:{seconds % 60:02d}"


def _safe_path_part(value: Any) -> str:
    text = str(value or "").strip()
    text = re.sub(r'[<>:"/\\|?*\s]+', "_", text)
    text = text.strip("._")
    return text[:80] or "unknown"
```

说明：

- 使用标准库 `urllib`，不用新增 `requests` 依赖。
- `download_ucms_video()` 返回 `path` 是相对项目根目录路径，可直接给现有 `_resolve_input_video()` 使用。
- 下载的 `.json` sidecar 保存远程元信息，方便后续排查素材来源。

### 6.7 修改 `/api/run`：远程视频启动时先下载

替换当前这行：

```python

```

为：

```python
input_path = _prepare_run_input_video(req)
```

新增函数：

```python
def _prepare_run_input_video(req: RunRequest) -> Path | None:
    if req.remote_video:
        try:
            downloaded = download_ucms_video(
                REMOTE_UCMS_CONFIG,
                req.remote_video,
                root_dir=ROOT,
                force=req.force_remote_download,
            )
        except Exception as exc:
            raise HTTPException(502, f"远程视频下载失败: {exc}")
        req.input_video = downloaded["path"]
        return _resolve_input_video(downloaded["path"])

    if req.input_video:
        return _resolve_input_video(req.input_video)

    return None
```

### 6.8 修改任务指纹，避免远程视频重复任务冲突

当前 `_run_fingerprint()` 只基于本地文件 path/size/mtime + production_mode。远程缓存文件只要稳定，已可复用。但建议把远程 id 也加入指纹，让任务更清晰：

```python
def _run_fingerprint(req: RunRequest, input_path: Path | None) -> str:
    payload = {
        "video": _video_fingerprint(input_path) if input_path else None,
        "remote": _remote_video_fingerprint(req.remote_video),
        "production_mode": req.production_mode,
    }
    raw = json.dumps(payload, ensure_ascii=False, sort_keys=True)
    return hashlib.sha256(raw.encode("utf-8")).hexdigest()[:16]


def _remote_video_fingerprint(remote_video: dict[str, Any] | None) -> dict[str, Any] | None:
    if not remote_video:
        return None
    return {
        "source_type": remote_video.get("source_type") or "remote_ucms",
        "id": remote_video.get("id") or remote_video.get("remote_id"),
        "guid": remote_video.get("guid", ""),
        "name": remote_video.get("name", ""),
        "record_station": remote_video.get("record_station") or remote_video.get("recordStation", ""),
        "download_url": remote_video.get("download_url") or remote_video.get("media_high_url") or remote_video.get("mediaHigh", ""),
    }
```

### 6.9 任务名建议使用远程素材名

当前 `_make_task_id_from_fingerprint()` 使用 `input_video` 的 stem。远程缓存文件名会是 `id_name.mp4`，可接受。若想更美观，可新增：

```python
def _display_input_name(req: RunRequest) -> str | None:
    if req.remote_video:
        return str(req.remote_video.get("name") or req.remote_video.get("remote_id") or "remote_video")
    return req.input_video
```

然后 `/api/run` 里：

```python
input_name_for_task = _display_input_name(req)
if req.input_video and not req.task_id:
    task_id = _make_task_id_from_fingerprint(input_name_for_task, req.production_mode, fingerprint)
else:
    task_id = _resolve_run_task_id(req)
```

不过第一版不做也可以。

### 6.10 在 manifest 中记录远程源信息

因为 pipeline 的 manifest 只知道本地 `source_video`，建议 `/api/run` 下载完后把远程信息写入任务目录。可以在 `task_dir = ensure_dir(OUTPUTS_DIR / task_id)` 后新增：

async function loadRemoteVideos(page = 1) {
  const box = $("remoteVideoList");
  if (!box) return;
  if (!state.remoteEnabled) {
    box.innerHTML = `<div class="list-item"><strong>远程素材未启用</strong><span>请检查 config.toml</span></div>`;
    return;

function renderRemoteVideos() {
  const box = $("remoteVideoList");
  if (!box) return;
  const p = state.remotePagination || {};
  const maxPage = Math.max(1, Math.ceil((p.total || 0) / (p.pageSize || 30)));
  if ($("remotePageInfo")) $("remotePageInfo").textContent = `${p.current || 1} / ${maxPage} · 共 ${p.total || 0}`;

    ? ""
    : `<div class="list-item"><strong>没有远程素材</strong><span>请更换信号源或稍后刷新</span></div>`;

  state.remoteVideos.forEach((video) => {
    const item = document.createElement("button");
    item.className = `list-item ${state.selectedRemoteVideo?.remote_id === video.remote_id ? "active" : ""}`;
    item.type = "button";

    item.addEventListener("click", () => selectRemoteVideo(video));
    box.appendChild(item);

  lucide.createIcons();
}

function renderRemoteError(error) {
  const box = $("remoteVideoList");

## 11. 关键兼容点

### 11.1 保持 `python run_web.py`

无需修改 `run_web.py`。它仍然启动 `web_app:app`，新增接口都挂在同一个 FastAPI app 下。

### 11.2 不破坏已有本地素材入口

`/api/videos`、`/api/videos/upload`、`/api/videos/preview` 保持原样。远程素材新增 `/api/remote-videos`，避免影响本地列表。

### 11.3 不改 pipeline 核心处理逻辑

远程下载发生在 Web 层，pipeline 仍接收本地文件路径。这样不会影响：

- metadata
- audio_extract
- frame_extract
- chunk_build
- asr
- vision
- timeline
- AI 配音模式
- 高光重组模式

### 11.4 缓存目录必须在项目根目录内

因为 `_resolve_input_video()` 要求 input 在项目目录内，所以 `cache_dir` 必须是项目根目录下的相对目录，例如：

```toml
cache_dir = "data/remote_videos"
```

不要配置成 `D:\remote_videos` 或 `/mnt/remote_videos`，否则会被 `_resolve_input_video()` 拒绝。除非你同步修改安全策略。

## 12. 异常处理建议

### 12.1 UCMS 列表接口失败

`/api/remote-videos` 返回 502，前端只在远程素材区展示错误，不影响本地工作台。

### 12.2 下载失败

`/api/run` 返回 502：

```text
远程视频下载失败: 请求 UCMS 失败 / HTTP 403 / timeout / URL为空
```

前端 `afterJobStarted` 不会执行，用户停留当前页面。

### 12.3 mediaHigh 为空

下载逻辑优先：

```text
prefer_quality=high → mediaHigh.url → mediaLow.url
prefer_quality=low  → mediaLow.url → mediaHigh.url
```

### 12.4 重复下载

如果本地缓存文件存在且 size > 0，则直接复用，不重新下载。需要重新下载时传：

```json
{"force_remote_download": true}
```

第一版前端可以不暴露这个选项。
