下面是基于我实际按路径读取代码后的改造方案，重点围绕你要的 **网页音色选择 + 服务端内置音色 + 支持试听 + 生成视频时使用所选音色**。

## 1. 当前代码现状

这个项目入口链路是：

`python run_web.py` → `uvicorn.run("web_app:app")` → Web 页面提交 `/api/run` → `web_app.py` 拼 CLI 命令 → 子进程执行 `run_pipeline.py` → `newsclip_agent.pipeline.main()` → `PipelineRunner.run()`。

`run_web.py` 只负责从 7860 起找空闲端口，然后启动 `web_app:app`，所以这个改造不需要改变启动方式，仍然保持 `python run_web.py`。

当前 Web 的 `RunRequest` 里已经有 `require_tts / audio_policy / production_mode` 等 TTS 相关参数，但没有 `voice_id`、`voice_name` 或音色选择字段。

`web_app.py` 的 `_build_run_command()` 会把页面参数转成命令行参数，例如 `--target-duration`、`--audio-policy`、`--production-mode`，但现在没有传音色参数。

当前 `config.toml` 只有一个 `[omnivoice]` 配置，里面写死了 `model_path / reference_audio / reference_text / speed`，也就是说整个系统只有一个参考音频。

真正生成配音的位置在 `newsclip_agent/pipeline.py` 的 `_step_tts_impl()`。这里每次都会从 `self.config.omnivoice` 里读取固定的 `reference_audio` 和 `reference_text`，然后调用 `generate_omnivoice_audio()`。 同一个固定引用音频也出现在非分段 TTS 逻辑里。

前端页面目前有 `TTS` 必须成功/允许跳过的选择，但没有音色选择 UI。 前端提交请求的 `baseRunRequest()` 也没有带音色参数。

## 2. 问题原因

现在音色不能选，不是 OmniVoice 本身的问题，而是工程链路里没有把“音色”抽象成一个可配置对象。

当前写死点主要有 4 个：

第一，`config.toml` 只有单个 `[omnivoice]`，没有音色列表。

第二，`web_app.py /api/config` 只返回 workflow、short_video、voiceover、remote_ucms，没有返回音色列表。

第三，前端没有音色选择控件，也没有试听按钮。

第四，`pipeline.py` 的 TTS 步骤直接读 `self.config.omnivoice.get("reference_audio")`，没有根据用户选择切换参考音频。

```python
def _voice_catalog() -> dict[str, dict[str, Any]]:
    voices = PROJECT_CONFIG.raw.get("voices", {})
    if not isinstance(voices, dict):
        voices = {}

    catalog: dict[str, dict[str, Any]] = {}

    for key, item in voices.items():
        if not isinstance(item, dict):
            continue
        voice_id = str(item.get("id") or key).strip()
        if not voice_id:
            continue
        if item.get("enabled") is False:
            continue

        catalog[voice_id] = {
            "id": voice_id,
            "name": str(item.get("name") or voice_id),
            "description": str(item.get("description") or ""),
            "style": str(item.get("style") or ""),
            "gender": str(item.get("gender") or ""),
            "reference_audio": str(item.get("reference_audio") or ""),
            "reference_text": str(item.get("reference_text") or ""),
            "preview_audio": str(item.get("preview_audio") or item.get("reference_audio") or ""),
            "speed": item.get("speed"),
        }

    # 兼容旧配置：如果没配 [voices]，就把 [omnivoice] 包装成一个默认音色
    if not catalog:
        default_id = str(PROJECT_CONFIG.omnivoice.get("default_voice_id") or "default")
        catalog[default_id] = {
            "id": default_id,
            "name": "默认音色",
            "description": "来自 [omnivoice] 默认参考音频",
            "style": "default",
            "gender": "",
            "reference_audio": str(PROJECT_CONFIG.omnivoice.get("reference_audio") or ""),
            "reference_text": str(PROJECT_CONFIG.omnivoice.get("reference_text") or ""),
            "preview_audio": str(PROJECT_CONFIG.omnivoice.get("reference_audio") or ""),
            "speed": PROJECT_CONFIG.omnivoice.get("speed"),
        }

    return catalog


def _public_voice_catalog() -> list[dict[str, Any]]:
    default_voice_id = str(PROJECT_CONFIG.omnivoice.get("default_voice_id") or "")
    items = []
    for voice in _voice_catalog().values():
        items.append({
            "id": voice["id"],
            "name": voice["name"],
            "description": voice["description"],
            "style": voice["style"],
            "gender": voice["gender"],
            "preview_url": f"/api/voices/{voice['id']}/preview",
            "is_default": bool(default_voice_id and voice["id"] == default_voice_id),
        })
    return items
```

```python
@app.get("/api/voices/{voice_id}/preview")
def preview_voice(voice_id: str):
    voice = _voice_catalog().get(voice_id)
    if not voice:
        raise HTTPException(404, "voice not found")

    preview = voice.get("preview_audio") or voice.get("reference_audio")
    if not preview:
        raise HTTPException(404, "voice preview audio missing")

    path = PROJECT_CONFIG.resolve_path(str(preview))
    if not path or not path.exists() or not path.is_file():
        raise HTTPException(404, "voice preview file not found")

    root = ROOT.resolve()
    resolved = path.resolve()

    # 限制必须在项目目录内，避免任意文件读取
    if root != resolved and root not in resolved.parents:
        raise HTTPException(400, "voice preview must be inside project directory")

    return FileResponse(str(resolved))
```

### C. 增加 `_resolve_voice_config()` 方法

放在 `PipelineRunner` 类里，建议放在 `_run_options_payload()` 附近：

```python
def _resolve_voice_config(self) -> dict[str, Any]:
    base = dict(self.config.omnivoice)
    voices = self.config.raw.get("voices", {})
    if not isinstance(voices, dict):
        voices = {}

    requested = (self.options.voice_id or base.get("default_voice_id") or "").strip()
    selected_id = requested

    selected = {}
    if requested and requested in voices and isinstance(voices[requested], dict):
        selected = dict(voices[requested])
    elif voices:
        # 兜底：找第一个 enabled != false 的音色
        for key, value in voices.items():
            if isinstance(value, dict) and value.get("enabled") is not False:
                selected_id = str(value.get("id") or key)
                selected = dict(value)
                break

    if selected:
        merged = {**base, **selected}
        merged["voice_id"] = str(selected.get("id") or selected_id)
        merged["voice_name"] = str(selected.get("name") or merged["voice_id"])
    else:
        merged = base
        merged["voice_id"] = str(base.get("default_voice_id") or "default")
        merged["voice_name"] = "默认音色"

    return merged
```

### C. 新增 `fillVoiceSelect()`

```javascript
function fillVoiceSelect() {
  const select = $("voiceSelect");
  if (!select) return;

  const voices = state.voices || [];
  if (!voices.length) {
    select.innerHTML = `<option value="">默认音色</option>`;
    return;
  }

  select.innerHTML = voices
    .map((voice) => {
      const label = [
        voice.name || voice.id,
        voice.gender ? genderLabel(voice.gender) : "",
        voice.style ? styleLabel(voice.style) : "",
      ].filter(Boolean).join(" · ");
      return `<option value="${escapeAttr(voice.id)}">${escapeHtml(label)}</option>`;
    })
    .join("");

  const defaultVoice =
    voices.find((v) => v.is_default) ||
    voices.find((v) => v.id === state.defaultVoiceId) ||
    voices[0];

  if (defaultVoice) select.value = defaultVoice.id;
}

function genderLabel(value) {
  return { male: "男声", female: "女声" }[value] || value;
}

function styleLabel(value) {
  return {
    news: "新闻",
    explainer: "解说",
    default: "默认",
  }[value] || value;
}
```

```javascript
  only_analysis: mode === "only_analysis",
  skip_tts: productionMode === "highlight_reassembly",
  skip_render: mode === "skip_render",
  mode: "normal",
  client_id: getClientId(),
};
```

改完后，Web 页面会变成：

```text

画面比例：16:9 / 9:16
Chunk 秒数
抽帧间隔
TTS：必须成功 / 允许跳过
配音音色：默认女声 / 男声新闻 / 温和解说

```

用户选择音色后，提交 `/api/run`：

```json
{
  "production_mode": "ai_voiceover",
  "voice_id": "male_news",
  "audio_policy": "ai_voiceover",
  "require_tts": true
}
```

`web_app.py` 会拼成：

```powershell
python run_pipeline.py --task-id xxx --voice-id male_news ...
```

`pipeline.py` 会根据 `voice_id` 读取对应的 `reference_audio / reference_text / speed`，然后传给 OmniVoice 生成配音。

高光重组模式不受影响，因为它会强制：

```python
req.audio_policy = "original"
req.require_tts = False
req.skip_tts = True
```

这个逻辑当前已经在 `web_app.py` 里存在。
