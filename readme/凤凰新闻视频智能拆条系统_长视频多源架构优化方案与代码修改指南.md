# 凤凰新闻视频智能拆条系统：长视频 / 多源剪辑架构优化方案与代码修改指南

> 适用仓库：`angelOnly/AutomaticEditing`  
> 分支：`clean-highlight-reassembly`  
> Web 启动方式：保持 `python run_web.py` 不变  
> 项目入口：`run_web.py`  
> 核心目标：把当前“多源虚拟长时间轴串行分析”升级为“按源视频并行事实分析 + 全局编辑决策”的生产级架构，以支持更长视频、更多源视频、更稳定的 AI 配音剪辑与高光重组。

---

## 0. 结论先行

当前代码已经不是纯 demo，有以下基础能力：

```text
1. Web 工作台与任务队列
2. 单源 AI 配音模式
3. 单源/多源高光重组模式
4. 多源 source_request.json
5. common analysis 复用机制
6. multi_source_virtual 虚拟时间轴
7. FunASR GPU 锁
8. TTS / render 资源锁
9. vision chunk 并发
10. 高光重组对虚拟多源的回源裁剪支持
```

但目前最大的问题是：

```text
多源只是“虚拟成一个长时间轴”；
并没有做到“每个源视频独立并行分析”。
```

所以长视频或 10 个源视频时，仍然会出现：

```text
多个视频 -> 一个虚拟长任务 -> metadata/audio/frame/asr/vision/timeline_digest
```

这会导致：

```text
1. 抽音频、抽帧、ASR 仍然大量串行
2. 某一个源视频失败会拖累整个任务
3. 缓存粒度太粗，不利于复用
4. LLM 后续输入容易越来越重
5. 长视频覆盖率和成片数量难以稳定控制
6. AI 配音模式对虚拟多源回源裁剪不如高光重组完善
```

推荐最终架构：

```text
Source-level Parallel Analysis + Global Editorial Planning

阶段 A：每个源视频独立事实分析，可并行
阶段 B：汇总轻量 source_aggregate
阶段 C：全局大模型统一做编辑决策
阶段 D：渲染阶段按 source_id 回源裁剪
```

## 2. 当前主要问题原因

### 2.1 多源没有 source-level 并发

虚拟多源的 `audio_extract` 现在是：

```python
for item in self._iter_source_items():
    source_id = item["source_id"]
    source = self._resolve_source_item_path(item)
    ...
    run_cmd(["ffmpeg", ...])
```

这是按 source 串行。

虚拟多源的 `frame_extract` 也是：

```python
for item in self._iter_source_items():
    source_id = item["source_id"]
    source = self._resolve_source_item_path(item)
    ...
    run_cmd(["ffmpeg", ...])
```

也是串行。

ASR 虽然有 GPU 锁：

```python
with file_slot_lock("asr", slots=asr_slots):
```

但锁内仍然是：

```python
for index, window in enumerate(windows, start=1):
    result = engine.transcribe(str(seg_audio))
```

所以 ASR window 串行。

结论：

```text
现在只是 chunk 级部分并发，不是 source 级并发。
```

---

### 2.2 common analysis 复用粒度太粗

当前 common analysis 的缓存对象是整个虚拟多源任务：

```text
common_<source_key>/
  metadata/
  audio_extract/
  frame_extract/
  asr/
  vision/
  timeline/
  timeline_digest/
```

如果 10 个视频里只有 1 个视频变了，理论上应该只重跑这个视频的分析。

但当前架构容易导致整个 common analysis 失效。

推荐改成：

```text
source_analysis/v1/source_001/
source_analysis/v1/source_002/
source_analysis/v1/source_003/
...
source_aggregate/v1/source_aggregate.json
```

这样缓存粒度更细，失败隔离也更好。

---

### 2.3 后续大模型输入仍然偏长

当前 `timeline_digest` 是把虚拟长时间轴里的全部 chunks 聚合后给后续步骤。

长视频时会出现：

```text
50 分钟 / chunk 60s = 50 个 chunk
10 个视频各 5 分钟 = 50 个 chunk
如果 frame_interval 更密，会更重
```

后续：

```text
content_analysis
video_understanding
highlight_detection
short_video_edit_plan
highlight_reassembly_plan
```

都容易吃到越来越长的上下文。

推荐新增：

```text
source_aggregate.json
```

它只保留：

```text
1. 每个 source 的摘要
2. 每个 source 的 key_facts
3. 轻量 timeline_digest
4. 候选片段池
5. 必要 source 边界信息
```

不汇总：

```text
raw ASR
raw_response
usage
latency
完整 debug
所有视觉原始结果
```

---

### 2.4 AI 配音模式对多源回源裁剪不完整

高光重组已有 `_resolve_reassembly_clip_source()`，可以根据：

```text
source_id
virtual_start_seconds
virtual_end_seconds
```

找到原始视频并换算成本地时间。

但 AI 配音的 `cut_plan/render` 仍然更偏向单源逻辑。`step_cut_plan()` 里还会尝试：

```python
source_duration = float(ffprobe_json(self._source_video()).get("duration") or 0)
```

虚拟多源下 `source_video` 为空，只能 fallback 到 0。

这会影响：

```text
1. 自动延长片段
2. source_duration 相关校验
3. 长源覆盖率 warning
4. 后续 render 回源裁剪
```

需要为 AI 配音模式补齐类似高光重组的多源回源能力。

## 5. `config.toml` 修改指南

### 5.1 新增 `[multi_source_analysis]`

在 `[multi_source]` 或 `[gpu_limits]` 附近新增：

```toml
[multi_source_analysis]
enabled = true

# 同时分析几个源视频。不要一开始开到 10，建议先 3。
source_max_workers = 3

# 单个 source 内部视觉 chunk 并发数。
# 因为 source 本身已经并发，所以单个 source 内不要再开太高。
per_source_vision_max_workers = 2

# 预留：全局视觉 LLM 最大并发。
# 第一版可以先不用 semaphore，只限制 source_max_workers 和 per_source_vision_max_workers。
vision_global_max_workers = 6

# 预留：全局文本 LLM 最大并发。
text_global_max_workers = 6

# partial_success：单个源失败不拖垮全部；全部失败才终止。
# fail_fast：任一源失败立即终止。
fail_policy = "partial_success"

# 每个源最多保留多少候选，后续 candidate_extract 可用。
max_candidates_per_source = 8

# 全局候选池最多保留多少条进入编辑规划。
max_global_candidate_clips = 40
```

---

### 5.2 放宽 AI 配音 compact 时长阈值

当前：

```toml
[voiceover]
compact_min_target_ratio = 0.65
compact_duration_tolerance_seconds = 1.0
compact_severe_short_ratio = 0.65
```

建议改：

```toml
[voiceover]
compact_min_target_ratio = 0.58
compact_duration_tolerance_seconds = 10.0
compact_severe_short_ratio = 0.58
```

原因：

当前 `cut_plan` 会计算：

```python
min_compact_duration = target_duration * compact_min_target_ratio
```

并在 compact TTS 成片时长过短时阻断渲染。

你的产品需求是：

```text
AI 配音差距宽松一点，从 65% 调成 58%，差 10 秒都算正常。
```

因此配置应同步调整。

## 9. 新增 `step_source_analysis()`

### 9.1 实现思路

最稳的一版不要复制 `metadata/audio/frame/asr/vision/timeline` 代码，而是复用现有单源 `PipelineRunner`。

每个 source：

```text
创建一个子任务目录
调用 PipelineRunner 跑单源 common steps
读取子任务 timeline_digest
生成 source_summary.json
```

这样可以：

```text
1. 复用现有单源能力
2. 减少重复代码
3. 继承现有缓存机制
4. 继承 ASR GPU 锁
5. 继承 vision chunk 并发
6. 单个 source 失败可隔离
```

---

### 9.2 可直接加入 `pipeline.py` 的代码

```python
def step_source_analysis(self) -> None:
    if not self._is_virtual_multi_source():
        raise RuntimeError("source_analysis 只用于 multi_source_virtual")

    cfg = self.config.raw.get("multi_source_analysis", {})
    max_workers = max(1, int(cfg.get("source_max_workers", 3) or 3))
    fail_policy = str(cfg.get("fail_policy", "partial_success") or "partial_success")

    sources = self._iter_source_items()
    input_hash = stable_hash({
        "version": "source_analysis_v1",
        "sources": [
            {
                "source_id": s.get("source_id"),
                "path": s.get("original_path"),
                "mtime": self._resolve_source_item_path(s).stat().st_mtime
                if self._resolve_source_item_path(s).exists()
                else 0,
            }
            for s in sources
        ],
        "chunk_seconds": self.options.chunk_seconds,
        "frame_interval": self.options.frame_interval,
        "mode": self.options.mode,
        "vision_max_frames_per_chunk": self.options.vision_max_frames_per_chunk,
    })

    if self._can_reuse("source_analysis", input_hash):
        print("复用缓存: source_analysis")
        return

    version, vdir = self._version_dir("source_analysis", "source_analysis")
    ensure_dir(vdir)

    def run_one(index: int, item: dict[str, Any]) -> tuple[int, dict[str, Any]]:
        source_id = str(item.get("source_id") or f"source_{index + 1:03d}")
        source_path = self._resolve_source_item_path(item)
        source_root = ensure_dir(vdir / source_id)
        work_outputs_dir = source_root / "_work"

        try:
            child_options = RunOptions(
                input=str(source_path),
                task_id=source_id,
                config=self.options.config,
                outputs_dir=relpath(work_outputs_dir, self.root),
                resume=True,
                chunk_seconds=self.options.chunk_seconds,
                frame_interval=self.options.frame_interval,
                vision_max_workers=max(
                    1,
                    int(
                        cfg.get("per_source_vision_max_workers")
                        or min(2, self.options.vision_max_workers)
                    ),
                ),
                vision_max_frames_per_chunk=self.options.vision_max_frames_per_chunk,
                aspect_ratio=self.options.aspect_ratio,
                mode=self.options.mode,
                production_mode="ai_voiceover",
                common_only=True,
                release_asr_after_task=True,
            )

            runner = PipelineRunner(child_options)
            runner.run()

            child_task_dir = work_outputs_dir / source_id
            summary = self._build_source_analysis_summary(
                source_id=source_id,
                item=item,
                child_task_dir=child_task_dir,
            )
            summary["status"] = "success"
            write_json(source_root / "source_summary.json", summary)
            return index, summary

        except Exception as exc:
            failed = {
                "source_id": source_id,
                "status": "failed",
                "display_name": item.get("display_name", ""),
                "original_path": item.get("original_path", ""),
                "error": str(exc),
            }
            write_json(source_root / "source_summary.json", failed)

            if fail_policy == "fail_fast":
                raise

            return index, failed

    results: list[tuple[int, dict[str, Any]]] = []

    with ThreadPoolExecutor(max_workers=max_workers) as pool:
        futures = [
            pool.submit(run_one, index, item)
            for index, item in enumerate(sources)
        ]

        for future in as_completed(futures):
            result = future.result()
            results.append(result)
            done = len(results)
            self._update_step_progress(
                "source_analysis",
                f"多源素材分析 {done}/{len(sources)}",
                {
                    "processed_sources": done,
                    "total_sources": len(sources),
                },
            )

    results.sort(key=lambda x: x[0])
    source_results = [item for _, item in results]

    failed = [x for x in source_results if x.get("status") == "failed"]
    success = [x for x in source_results if x.get("status") == "success"]

    output = {
        "version": "source_analysis_v1",
        "source_count": len(source_results),
        "success_count": len(success),
        "failed_count": len(failed),
        "sources": source_results,
    }

    out = write_json(vdir / "source_analysis.json", output)

    status = "success" if not failed else "partial_success"
    if not success:
        status = "failed"

    status_doc = self._base_status("source_analysis", version, input_hash, [out])
    status_doc["status"] = status
    status_doc["summary"] = {
        "source_count": len(source_results),
        "success_count": len(success),
        "failed_count": len(failed),
        "max_workers": max_workers,
    }
    self._write_status(vdir, status_doc)

    self._record_step(
        step="source_analysis",
        version=version,
        status=status,
        output=relpath(out, self.task_dir),
        input_hash=input_hash,
        output_files=[out],
        extra={
            "summary": {
                "source_count": len(source_results),
                "success_count": len(success),
                "failed_count": len(failed),
                "max_workers": max_workers,
            }
        },
    )

    if status == "failed":
        raise RuntimeError("所有源视频分析失败，无法继续")
```

```python
def _build_source_analysis_summary(
    self,
    *,
    source_id: str,
    item: dict[str, Any],
    child_task_dir: Path,
) -> dict[str, Any]:
    child_manifest = read_json(child_task_dir / "manifest.json", {})
    steps = child_manifest.get("steps", {})

    def load_step(step: str, default: Any) -> Any:
        output = steps.get(step, {}).get("output")
        if not output:
            return default
        return read_json(child_task_dir / output, default)

    metadata = load_step("metadata", {})
    timeline_digest = load_step("timeline_digest", {"chunks": []})
    timeline = load_step("timeline", {"timeline": []})
    asr_digest = load_step("asr_digest", {"chunks": []})

    duration = float(
        metadata.get("duration")
        or item.get("duration_seconds")
        or item.get("original_duration_seconds")
        or 0
    )

    chunks = timeline_digest.get("chunks", [])

    key_facts: list[str] = []
    for chunk in chunks[:8]:
        speech = str(chunk.get("speech") or "").strip()
        visual = str(chunk.get("visual") or "").strip()
        text = speech or visual
        if text:
            key_facts.append(text[:120])

    source_summary = "；".join(key_facts[:3])

    return {
        "source_id": source_id,
        "source_index": item.get("source_index"),
        "source_type": item.get("source_type", ""),
        "display_name": item.get("display_name", ""),
        "original_path": item.get("original_path", ""),
        "duration_seconds": round(duration, 3),
        "virtual_start_seconds": item.get("virtual_start_seconds", 0),
        "virtual_end_seconds": item.get("virtual_end_seconds", 0),
        "summary": source_summary,
        "key_facts": key_facts,
        "timeline_digest": timeline_digest,
        "timeline": timeline,
        "asr_digest": asr_digest,
        "child_task_dir": relpath(child_task_dir, self.task_dir),
        "child_steps": {
            key: {
                "status": value.get("status"),
                "output": value.get("output"),
            }
            for key, value in steps.items()
            if key in {
                "metadata",
                "audio_extract",
                "frame_extract",
                "chunk_build",
                "asr",
                "asr_digest",
                "vision",
                "timeline",
                "timeline_digest",
            }
        },
    }
```

```python
def step_source_aggregate(self) -> None:
    source_analysis = self._load_step_json("source_analysis")
    cfg = self.config.raw.get("multi_source_analysis", {})
    llm_input_cfg = self.config.raw.get("llm_input", {})

    input_hash = stable_hash({
        "version": "source_aggregate_v1",
        "source_analysis": self._step_content_hash("source_analysis"),
        "cfg": cfg,
        "llm_input": llm_input_cfg,
    })

    if self._can_reuse("source_aggregate", input_hash):
        print("复用缓存: source_aggregate")
        return

    version, vdir = self._version_dir("source_aggregate", "source_aggregate")
    ensure_dir(vdir)

    source_summaries: list[dict[str, Any]] = []
    all_chunks: list[dict[str, Any]] = []

    for source in source_analysis.get("sources", []):
        if source.get("status") != "success":
            continue

        source_id = str(source.get("source_id") or "")
        virtual_start = float(source.get("virtual_start_seconds") or 0)
        virtual_end = float(source.get("virtual_end_seconds") or 0)

        source_summaries.append({
            "source_id": source_id,
            "source_index": source.get("source_index"),
            "source_type": source.get("source_type", ""),
            "display_name": source.get("display_name", ""),
            "duration_seconds": source.get("duration_seconds", 0),
            "virtual_start_seconds": virtual_start,
            "virtual_end_seconds": virtual_end,
            "summary": compact_text(
                str(source.get("summary") or ""),
                max_chars=300,
            ),
            "key_facts": source.get("key_facts", [])[:8],
        })

        timeline_digest = source.get("timeline_digest", {})
        for chunk in timeline_digest.get("chunks", []):
            if not isinstance(chunk, dict):
                continue

            c = dict(chunk)

            local_start = float(c.get("start_seconds") or 0)
            local_end = float(c.get("end_seconds") or 0)

            global_chunk_id = f"{source_id}_{c.get('chunk_id') or len(all_chunks) + 1}"

            c["source_id"] = source_id
            c["local_start_seconds"] = round(local_start, 3)
            c["local_end_seconds"] = round(local_end, 3)
            c["start_seconds"] = round(virtual_start + local_start, 3)
            c["end_seconds"] = round(virtual_start + local_end, 3)
            c["global_chunk_id"] = global_chunk_id
            c["chunk_id"] = global_chunk_id

            all_chunks.append(c)

    output = {
        "version": "source_aggregate_v1",
        "source_count": len(source_summaries),
        "sources": source_summaries,
        "timeline_digest": {
            "version": "multi_source_timeline_digest_v1",
            "video_duration_seconds": max(
                [float(s.get("virtual_end_seconds") or 0) for s in source_summaries],
                default=0.0,
            ),
            "chunks": all_chunks,
        },
    }

    out = write_json(vdir / "source_aggregate.json", output)

    status_doc = self._base_status("source_aggregate", version, input_hash, [out])
    status_doc["summary"] = {
        "sources": len(source_summaries),
        "chunks": len(all_chunks),
    }

    self._write_status(vdir, status_doc)

    self._record_step(
        step="source_aggregate",
        version=version,
        status="success",
        output=relpath(out, self.task_dir),
        input_hash=input_hash,
        output_files=[out],
        extra={
            "summary": {
                "sources": len(source_summaries),
                "chunks": len(all_chunks),
            }
        },
    )
```

### 13.1 新增 `_resolve_ai_clip_source()`

```python
def _resolve_ai_clip_source(self, clip: dict[str, Any]) -> tuple[Path, float, float]:
    start = timecode_to_seconds(clip.get("source_start"))
    end = timecode_to_seconds(clip.get("source_end"))

    if end <= start:
        raise RuntimeError(f"invalid AI clip time range: {clip.get('clip_id') or ''}")

    if not self._is_virtual_multi_source():
        return self._source_video(), start, end

    source_id = str(clip.get("source_id") or "").strip()

    for item in self._iter_source_items():
        item_source_id = str(item.get("source_id") or "").strip()
        if source_id and item_source_id != source_id:
            continue

        virtual_start = float(item.get("virtual_start_seconds") or 0)
        virtual_end = float(item.get("virtual_end_seconds") or 0)

        if virtual_start <= start and end <= virtual_end:
            source_path = self._resolve_source_item_path(item)
            return source_path, start - virtual_start, end - virtual_start

    raise RuntimeError(
        "AI 配音剪辑失败：片段时间不在任何源视频边界内。\n"

        "可能原因：模型输出了局部时间而不是虚拟全局时间，或遗漏 source_id。\n"
        "处理办法：请从 short_video_edit_plan 重跑；如果仍失败，需要检查多源提示词。"
```

### 13.2 新增 `_normalize_ai_clip_to_source_boundaries()`

```python
def _normalize_ai_clip_to_source_boundaries(self, clip: dict[str, Any]) -> list[dict[str, Any]]:
    if not self._is_virtual_multi_source():
        return [dict(clip)]

    start = timecode_to_seconds(clip.get("source_start"))
    end = timecode_to_seconds(clip.get("source_end"))

    if end <= start:
        return []

    requested_source_id = str(clip.get("source_id") or "").strip()
    normalized: list[dict[str, Any]] = []

    for item in self._iter_source_items():
        item_source_id = str(item.get("source_id") or "").strip()
        if requested_source_id and item_source_id != requested_source_id:
            continue

        virtual_start = float(item.get("virtual_start_seconds") or 0)
        virtual_end = float(item.get("virtual_end_seconds") or 0)

        seg_start = max(start, virtual_start)
        seg_end = min(end, virtual_end)

        if seg_end <= seg_start:
            continue

        new_clip = dict(clip)
        new_clip["source_id"] = item_source_id
        new_clip["source_index"] = item.get("source_index")
        new_clip["source_start"] = seconds_to_timecode(seg_start, ms=True)
        new_clip["source_end"] = seconds_to_timecode(seg_end, ms=True)
        new_clip["duration_seconds"] = round(seg_end - seg_start, 3)

        if seg_start != start or seg_end != end:
            new_clip["boundary_adjusted"] = True
            new_clip["boundary_reason"] = "自动按多源素材边界裁剪/拆分"

        normalized.append(new_clip)

    return normalized
```

```python
_SENTENCE_SPLIT_RE = re.compile(r"(?<=[。！？；?!;])")


def compact_text(text: str, max_chars: int = 320) -> str:
    text = re.sub(r"\s+", " ", text or "").strip()
    if len(text) <= max_chars:
        return text

    parts = _SENTENCE_SPLIT_RE.split(text)
    selected: list[str] = []
    total = 0

    for part in parts:
        part = part.strip()
        if not part:
            continue

        if total + len(part) > max_chars:
            break

        selected.append(part)
        total += len(part)

    if selected:
        return "".join(selected).strip()

    return text[:max_chars].strip() + "..."
```

```text

渲染
```

既然新的多源架构已经升级为：

```text
source_analysis
source_aggregate
global editorial planning
render by source_id
```

那么单源完全可以看成：

```text
source_analysis(source_001)
source_aggregate(只有一个 source)
global editorial planning
render by source_id
```

所以更合理的最终形态是：

```text
单源 = source_count 为 1 的统一 Source Pipeline
多源 = source_count 为 N 的统一 Source Pipeline
```

## 22.2 为什么不建议继续维护单源独立主线

如果继续保持：

```text
单源一条线
多源一条线
```

会出现长期维护问题：

```text
1. 多源持续优化，单源无法自动享受新架构收益。
2. bug 修复要同时考虑 legacy 单源和新多源。
3. prompt、candidate_refine、cut_plan、render 都会出现两套适配。
4. 单源无法复用 source_aggregate、source_id 回源裁剪等新能力。
5. 后续功能越做越多，代码分叉会越来越严重。
```

因此建议：

```text
不要删除旧单源代码；
但 Web 主流程不再默认调用旧单源 pipeline。
```

也就是：

```text
旧单源 pipeline 保留做回滚、调试、历史兼容；
新任务统一走 run_multisource_pipeline.py。
```

### 22.6.2 建议改法

新增统一开关读取：

```python

        config.raw.get("workflow", {}).get("use_unified_source_pipeline", True)

```

在 `/api/run` 里收集 source items 后，不再只在 `len(raw_source_items) > 1` 时写 `source_request.json`。

```python
use_unified_source_pipeline = _use_unified_source_pipeline(config)

    or len(raw_source_items) > 1
```


## 22.21 最终判断

这个补充方向是推荐的。

更清晰的长期架构不是：

```text
单源 pipeline
多源 pipeline
```

而是：

```text
统一 Source Pipeline
```

其中：

```text
单源只是 1 个 source
多源只是 N 个 source
```

旧单源代码先保留，但逐步从 Web 主流程中退出。这样既不会破坏历史兼容，又能避免后续所有优化都只服务多源、单源长期落后的问题。
