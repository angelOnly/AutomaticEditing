结论：**这不是视频文件名中文导致的本地保存问题，而是 UCMS 返回的远程下载 URL 里包含了未转义的中文/特殊字符，`urllib.request` 在发起 HTTP GET 时只能把 request path 按 ASCII 编码，于是直接炸了。**

报错点非常明确：

```text
UnicodeEncodeError: 'ascii' codec can't encode characters in position 24-29
...
http.client.py line 1287
return request.encode('ascii')
```

也就是 **HTTP 请求路径里有非 ASCII 字符**，大概率是类似：

```text
http://xxx/视频素材/凤凰新闻xxx.mp4
```

而不是：

```text
http://xxx/%E8%A7%86%E9%A2%91%E7%B4%A0%E6%9D%90/...
```

## 2. 问题原因

核心问题在 `newsclip_agent/remote_ucms.py`。

当前 `download_ucms_video()` 直接从 UCMS 数据里取：

```python
url = normalized.get("download_url") or normalized.get("media_high_url") or normalized.get("media_low_url")
```

然后直接调用：

```python
_download_file(str(url), tmp, headers=cfg.headers, timeout=cfg.request_timeout_seconds)
```



而 `_download_file()` 当前是这样写的：

```python
def _download_file(url: str, target: Path, *, headers: dict[str, str], timeout: int) -> None:
    ensure_dir(target.parent)
    req = urllib.request.Request(url, headers=headers, method="GET")
    try:
        with urllib.request.urlopen(req, timeout=timeout) as resp, target.open("wb") as out:
            for chunk in iter(lambda: resp.read(1024 * 1024), b""):
```

这里没有对 URL 做 percent-encode。Python 的 `urllib` 不会自动帮你把 URL 路径里的中文转成 `%E4%B8%AD%E6%96%87`，所以只要 UCMS 的 `mediaHigh.url` / `mediaLow.url` 带中文路径、中文文件名、空格等字符，就会在 `http.client` 里报 `UnicodeEncodeError`。

注意：`_safe_path_part()` 已经把本地缓存文件名里的空格、斜杠、特殊字符替换了，所以本地路径不是主要问题。

# 4. 具体修改方案

## 修改一：给远程下载 URL 做安全编码

在 `newsclip_agent/remote_ucms.py` 顶部增加 import：

```python
import urllib.parse
```

当前顶部已有：

```python
import urllib.error
import urllib.request
```



改成：

```python
import urllib.error
import urllib.parse
import urllib.request
```

然后在 `_download_file()` 前面新增函数：

```python
def _quote_url_for_http(url: str) -> str:
    """
    urllib/http.client 发送请求行时只能接受 ASCII。
    UCMS 返回的媒体 URL 可能包含中文路径、中文文件名、空格等字符，
    这里统一做 percent-encode，同时保留已有的 %xx 编码。
    """
    value = str(url or "").strip()
    if not value:
        raise RuntimeError("download url is empty")

    parts = urllib.parse.urlsplit(value)

    if parts.scheme not in {"http", "https"}:
        raise RuntimeError(f"unsupported download url scheme: {parts.scheme or 'empty'}")

    # netloc 理论上应是 ASCII；如果域名里有中文，用 IDNA 处理
    netloc = parts.netloc.encode("idna").decode("ascii")

    path = urllib.parse.quote(parts.path, safe="/:%@&=+$,;~!*'()[]-._%")
    query = urllib.parse.quote(parts.query, safe="=&?/:;+,%@~!*'()[]-._")
    fragment = urllib.parse.quote(parts.fragment, safe="=&?/:;+,%@~!*'()[]-._")

    return urllib.parse.urlunsplit((parts.scheme, netloc, path, query, fragment))
```

然后把 `_download_file()` 替换成下面这个版本：

```python
def _download_file(url: str, target: Path, *, headers: dict[str, str], timeout: int) -> None:
    ensure_dir(target.parent)

    safe_url = _quote_url_for_http(url)
    safe_headers = _ascii_safe_headers(headers)

    req = urllib.request.Request(safe_url, headers=safe_headers, method="GET")
    try:
        with urllib.request.urlopen(req, timeout=timeout) as resp, target.open("wb") as out:
            for chunk in iter(lambda: resp.read(1024 * 1024), b""):
                out.write(chunk)
    except urllib.error.HTTPError as exc:
        if target.exists():
            target.unlink(missing_ok=True)
        raise RuntimeError(f"remote video download failed: HTTP {exc.code}, url={_mask_url(safe_url)}") from exc
    except urllib.error.URLError as exc:
        if target.exists():
            target.unlink(missing_ok=True)
        raise RuntimeError(f"remote video download failed: {exc}, url={_mask_url(safe_url)}") from exc
    except Exception:
        if target.exists():
            target.unlink(missing_ok=True)
        raise
```

再新增两个辅助函数：

```python
def _ascii_safe_headers(headers: dict[str, str]) -> dict[str, str]:
    """
    HTTP header 本身也必须是可编码的。
    一般 Cookie / Authorization 都是 ASCII；这里做一次显式检查，
    避免后续报错位置不清楚。
    """
    safe: dict[str, str] = {}
    for key, value in (headers or {}).items():
        k = str(key)
        v = str(value)
        try:
            k.encode("latin-1")
            v.encode("latin-1")
        except UnicodeEncodeError as exc:
            raise RuntimeError(f"remote download header contains non-latin1 characters: {k}") from exc
        safe[k] = v
    return safe


def _mask_url(url: str) -> str:
    """
    日志里不要完整暴露签名参数、token、临时鉴权 query。
    """
    parts = urllib.parse.urlsplit(url)
    return urllib.parse.urlunsplit((parts.scheme, parts.netloc, parts.path, "", ""))
```

## 修改四：Web 错误提示增强，可选

现在单源远程下载失败时，Web 会包装成：

```python
raise HTTPException(502, f"remote video download failed: {exc}") from exc
```



多源任务不是立即下载，而是写 `source_request.json` 后由子进程下载，所以错误主要在 job log 里。`_extract_user_message_from_log()` 目前只提取 `运行失败：` 或 `RuntimeError:` 后面的内容，对 `UnicodeEncodeError` 这种 traceback 不够友好。

建议把 `_extract_user_message_from_log()` 增强一下：

```python
def _extract_user_message_from_log(path: Path) -> str:
    if not path.exists() or not path.is_file():
        return ""
    text = path.read_text(encoding="utf-8", errors="replace")

    marker = "运行失败："
    if marker in text:
        tail = text.rsplit(marker, 1)[-1].strip()
        tail = tail.split("可在任务表中查看失败步骤", 1)[0].strip()
        return tail

    if "UnicodeEncodeError" in text and "request.encode('ascii')" in text:
        return (
            "远程视频下载失败：UCMS 返回的视频 URL 含有未转义的中文或特殊字符，"
            "需要对下载 URL 做 percent-encode 后再请求。"
        )

    runtime_marker = "RuntimeError:"
    if runtime_marker in text:
        tail = text.rsplit(runtime_marker, 1)[-1].strip()
        lines = [line.strip() for line in tail.splitlines() if line.strip()]
        return "\n".join(lines[-4:])

    return ""
```

这个不是根因修复，但 Web 页面会更容易看懂。
